✨ OVERVIEW
------------------------------------------------------------------------
This website is a magical childhood friendship diary and memory scrapbook
designed for our inseparable squad of best friends. Combining Studio
Ghibli-inspired hand-painted anime scenery, warm pastel scrapbooks, school
memories, hilarious Tamil friendship banter, and a heartfelt lifetime promise.

🎮 INTERACTIVE FEATURES
------------------------------------------------------------------------
1. "Nee Ennaku Yaaru?" Welcome Quiz:
   - Fullscreen gatekeeper with 6 hilarious Tamil banter choices.
   - Speech bubble reactions and dynamic personalized welcome inside.

2. Background Melody Player ("Our little melody ♫"):
   - Plays local audio or automatically synthesizes a dreamy Ghibli music box
     lullaby using Web Audio API in real time.

3. Interactive Scrapbook Chapters:
   - 5 scrapbook chapters with editable, auto-saving memory notes in localStorage!

4. School Days — Our Inseparable Gang:
   - Beautiful friend cards for Keerthana, Vinothini, Rifana, Kavipriya,
     Vaithee, Subiii, and Kaviiii.
   - Editable nicknames and favorite memory boxes that auto-save on blur.

5. Polaroid Gallery with Lightbox:
   - Category filtering (All, Playground, Classroom, Funny Moments, Friendship).
   - Full-size lightbox with arrow keys and swipe controls.

6. Garden Path Timeline:
   - Animated flower milestone stepping stones.

7. Heartfelt Friendship Letter:
   - Emotional letter on warm textured paper with pressed flowers.

8. "Promise to Keep" Climax:
   - Sunset garden backdrop with glowing lanterns and fireflies.
   - Clicking "🤝 I Promise, Bestie 💗" triggers flower/heart bursts,
     a glowing halo, and 7 pulsing hearts for all friends!
